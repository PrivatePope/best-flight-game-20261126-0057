A complete flight game for the [make.fun bounty](https://make.fun/bounty/best-flight-game-20261126-0057) — cockpit view over recognisable terrain, instruments lit, a runway ahead, and altitude, speed and heading on the HUD. Played with keyboard and mouse in a desktop browser, from static files, no network.
